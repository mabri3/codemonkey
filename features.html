codemonkey

A scriptable coding-agent CLI (Python 3.11, uv, Typer, httpx) for OpenAI-style and Anthropic-style endpoints, defaulting to the local llama.cpp server (http://192.168.50.176:8080/v1, Qwen3.8-27B-NVFP4-MTP-VERY-HIGH.gguf). Non-interactive exec mode for CI/other agents; interactive rich REPL when run bare.

How to run

uv run codemonkey --version
uv run codemonkey config          # effective merged config (secrets masked)
uv run codemonkey models          # list models from the active provider
uv run pytest -q                  # unit suite (360 tests, no network)
uv run codemonkey exec "your prompt"          # non-interactive exec (text mode)
uv run codemonkey exec --json "your prompt"   # JSONL event stream on stdout
uv run codemonkey exec --output-schema s.json -o out.json "..."  # validated structured output
uv run codemonkey exec resume --last "follow-up"   # resume the latest session
uv run codemonkey sessions        # list persisted sessions
echo "your prompt" | uv run codemonkey exec - # prompt from stdin
uv run codemonkey undo --list     # checkpoints for THIS workspace
uv run codemonkey journal list    # execution-journal threads (now written by real runs)

Known limitations

  • Streaming retries cover the response status only: once tokens have been handed to the caller a mid-stream failure propagates rather than replaying the turn.
  • Retry-After is honored in its delta-seconds form; the HTTP-date form falls back to jittered backoff.
  • Live-LLM probes need a live endpoint. 2026-09-03: RESOLVED — the endpoint moved to 192.168.50.176:8080 (unsloth-studio, unsloth/Qwen3.8-27B-GGUF) and the full sweep runs A1–A20 green with zero BLOCKED rows, the first all-green live sweep of the project. The sweep's live gate now probes whatever the effective config resolves to, so a moved endpoint no longer reports BLOCKED.
  • The Anthropic native tool shape (input_schema) is unit-tested but has not been exercised against a live Anthropic endpoint — no key was available at cycle 51.
