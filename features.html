codemonkey

A scriptable coding-agent CLI (Python 3.11, uv, Typer, httpx) for OpenAI-style and Anthropic-style endpoints, defaulting to the local llama.cpp server (http://192.168.50.113:8080/v1, Qwen3.8-27B-NVFP4-MTP-VERY-HIGH.gguf). Non-interactive exec mode for CI/other agents; interactive rich REPL when run bare.

How to run

uv run codemonkey --version
uv run codemonkey config          # effective merged config (secrets masked)
uv run codemonkey models          # list models from the active provider
uv run pytest -q                  # unit suite (85 tests, no network)
uv run codemonkey exec "your prompt"          # non-interactive exec (text mode)
uv run codemonkey exec --json "your prompt"   # JSONL event stream on stdout
echo "your prompt" | uv run codemonkey exec - # prompt from stdin
# While the home llama.cpp inference is wedged (2026-09-02), live run:
CODEMONKEY_PROVIDER=unblock CODEMONKEY_UNBLOCK_KEY=... uv run codemonkey exec "..."

Known limitations

  • review / sessions / REPL commands are not wired yet (cycles 6–9). --output-schema is a deliberate exit-2 stub until cycle 6.
  • Structured output (--output-schema), session persistence, and pluggable strategies land in cycles 6–7.
  • Live-LLM probes need a live endpoint. 2026-09-02: the home llama.cpp server (192.168.50.113:8080) is reachable but its inference path is wedged — until it is restarted, live probes run through the temporary unblock provider (CODEMONKEY_PROVIDER=unblock, 127.0.0.1:3458 OpenCode Go proxy, model minimax-m3; needs CODEMONKEY_UNBLOCK_KEY).
